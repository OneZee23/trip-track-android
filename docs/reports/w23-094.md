- Fully hidden trips send `maxAltitude: 0.0` when public numbers use visible points. Regression coverage is in `TripSyncPayloadMapperTests`.
- Hidden routes use MapLibre white casing and round ink dots at 55% text-color opacity, with boundary locks. Route source/layer tests check the hidden features and paint properties; Robolectric does not render map tiles. The editor, trip hero, full-screen trip map, and own journey map use the hidden route geometry.
- Resolver and filming presentation work runs on a worker dispatcher for the trip detail, filming preparation, editor, publish sheet, journal, journey detail and atlas paths.
- The editor header now sits inside the sheet. Back and close discard staged edits; Done commits them. Updated editor screenshot baselines were reviewed.
