## Отличия и оставшееся

- Папка `ios-shots/` отсутствует. Для визуальной сверки использованы iOS UI test attachments из `.codex-work/shots/manifest.json` и `.codex-work/shots/` (onboarding, question, publish, privacy и own-map). Там нет editor- и filming-кадров, поэтому для этих экранов точная сверка с iOS не была доступна. На снимках Robolectric MapLibre tiles не загружаются; production экран использует live MapLibre style, но его карту нельзя проверить по локальному PNG.
- iOS показывает условный счётчик опубликованных поездок, чей маршрут скроется целиком, в вопросе выбора радиуса. Android пока не загружает этот счётчик на экране вопроса, поэтому дополнительная строка не появляется.
- На картах Android замок — собственный маркер MapLibre; на iOS эту метку рисует RouteMapView. Android включает автоматический режим записи экрана только на API 35+, где доступно нужное системное обнаружение.
